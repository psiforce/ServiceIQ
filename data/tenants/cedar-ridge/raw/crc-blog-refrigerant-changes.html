Refrigerant Changes: What Homeowners Should Know

R-22 (older systems)

R-22 production ended in 2020. Cedar Ridge does not offer R-22 recharges. If your R-22 system has a leak, we recommend a free replacement consultation.

R-410A (most systems from about 2010-2024)

R-410A remains available for servicing existing systems. We charge $95 per pound. Your existing R-410A system does not need to be replaced because of the refrigerant transition.

R-454B (new systems)

New residential systems now use lower-global-warming refrigerants such as R-454B. All new Aerotherm systems we install use R-454B. R-454B is charged at $125 per pound when service is needed.

Only EPA-certified technicians may handle refrigerant. Never attempt to add refrigerant yourself.
